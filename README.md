# AI-221-project

## overview 
the project analyzes cybercrime awareness among Saudi nationals using a dataset obtained from Kaggle

the project was developed as a part of the Artificial Intelligence programming course at Taibah university
## Dataset

The dataset used in this project was collected from:
[[Dataset Link]](https://www.kaggle.com/datasets/shashwatwork/cybercrime-awareness-among-saudi-nationals )

Before performing the data cleaning and analysis steps, the dataset was slightly modified to better fit the requirements of this project

## Results 
The analysis helps provide insights into the level of cybercrime awareness among Saudi nationals and highlights patterns found in the dataset after cleaning and preprocessing.
